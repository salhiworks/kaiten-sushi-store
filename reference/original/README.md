# Original component

The unmodified source of the **Sushi Conveyor Belt Menu** by DHxWhy, from
[21st.dev](https://21st.dev/@dhxwhy/components/sushi-conveyor-menu) (labelled MIT on its page), kept for comparison.

- `sushi-conveyor-menu.tsx`: the component. The version KAITEN uses is `src/components/ui/sushi-conveyor-menu.tsx`, with two small
  optional additions described at the top of that file.
- `demo.tsx`: the original usage example.

This folder is not part of the build.
